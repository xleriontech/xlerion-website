¿Quiénes Somos?

XLERION es una empresa colombiana de tecnología fundada en Bogotá, con más de 20 años de experiencia en desarrollo de software y soluciones digitales. Iniciamos en 2004 con el proyecto Redemthor (sitio web de la banda de metal colombiana) y evolucionamos hasta convertirnos en una empresa tecnológica completa en 2026.

Nos especializamos en crear soluciones modulares, toolkits técnicos para desarrollo empresarial, integración 3D con Three.js, y servicios de accesibilidad digital.

Servicios Principales

1. Toolkits Técnicos Enterprise

Desarrollamos herramientas modulares para empresas que necesitan:

  • Validación de datos: Sistemas de validación robustos para formularios, APIs y bases de datos
  • Logging y Diagnóstico: Herramientas de registro y análisis de errores en tiempo real
  • Performance Monitoring: Monitoreo de rendimiento y optimización de aplicaciones
  • Testing Automation: Suites de pruebas automatizadas y CI/CD integration

2. Desarrollo 3D e Integración Three.js

Creamos experiencias 3D interactivas para web usando tecnologías modernas:

  • Visualización de datos espaciales y gráficos 3D
  • Animaciones complejas con GSAP y sistemas de partículas
  • Shaders personalizados y efectos visuales avanzados
  • Integración con React y frameworks modernos

3. Total Darkness — Backend Modular

Sistema backend especializado para gestión de contenido dinámico:

  • Panel administrativo con autenticación segura (SQLite + PHP)
  • Gestión de historias y mundos digitales interactivos
  • APIs REST para integración con frontends
  • Sistema de roles y permisos granular

4. Turismo Incluyente

Soluciones de accesibilidad para personas con discapacidad visual:

  • Experiencias turísticas inclusivas en Bogotá, Colombia
  • Tecnología adaptativa y diseño universal (WCAG 2.1 AAA)
  • Audioguías y contenido descriptivo detallado
  • Mapas accesibles y navegación asistida

5. Desarrollo Web Moderno

Aplicaciones empresariales con tecnologías de vanguardia:

  • React 19, Vite 7, Tailwind CSS 3
  • Optimización SEO y renderizado del lado del servidor
  • Responsive design y progressive web apps (PWA)
  • Arquitecturas escalables y mantenibles

¿Por Qué el Sitio es Difícil de Indexar?

Nuestro sitio principal usa React (Single Page Application), lo que significa que el contenido se genera dinámicamente con JavaScript. Esto puede dificultar la indexación por buscadores temporalmente, pero estamos implementando mejoras de SEO:

  • ✅ Contenido estático HTML visible para Google (esta página)
  • ✅ Meta tags completos en todas las páginas
  • ✅ Structured Data (JSON-LD) con información de la organización
  • ✅ Sitemap XML con 29 rutas públicas
  • ✅ Robots.txt configurado correctamente
  • ✅ Archivos de verificación (humans.txt, security.txt)
  • 🔄 Implementación de Server-Side Rendering (próximamente)

Nota importante: El hecho de que un sitio sea difícil de indexar NO significa que sea fraudulento. Muchas empresas tecnológicas legítimas usan React/SPA y requieren tiempo para optimizar SEO.
