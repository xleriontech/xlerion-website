Concepto

¿Qué es BioQuest?

BioQuest es un sistema de gamificación ecológica integrado en la plataforma Biohostels que convierte la biodiversidad local de cada lote (800 m²) en una experiencia interactiva de descubrimiento, aprendizaje y recompensas. Los huéspedes, inversionistas y comunidad local pueden explorar, identificar y coleccionar especies nativas mientras contribuyen a la conservación y generan valor económico mediante BioCoin.

🎯

Objetivo Principal

Fomentar la conexión emocional con la biodiversidad local, educar sobre especies nativas y recompensar comportamientos sostenibles.

🔗

Integración

Conectado con IoT (sensores de biodiversidad), Blockchain (BioCoin rewards), El Flecho (proveedores locales) y el Libro Maestro (datos de especies).

🌟

Impacto

Cada especie descubierta genera datos científicos ciudadanos, contribuye a la conservación y fortalece la economía local.

Mecánicas

Sistema de Juego

🔍

Descubrimiento

Explora el Biohostel y sus alrededores para encontrar especies nativas. Usa la app para escanear, fotografiar e identificar flora y fauna.

📚

Colección

Cada especie descubierta se añade a tu "BioDex" personal. Completa colecciones por departamento, ecosistema o rareza para desbloquear logros.

⚔️

Misiones

Completa desafíos diarios, semanales y especiales: "Fotografía 5 orquídeas diferentes", "Identifica 3 aves endémicas", etc.

🏆

Competencia

Tablas de clasificación por Biohostel, vereda y departamento. Compite con otros huéspedes y gana recompensas exclusivas.

Tecnología

Integración Técnica

📱

App Móvil BioQuest

  • ✓ Escaneo de especies con IA (computer vision)
  • ✓ Geolocalización precisa dentro del Biohostel
  • ✓ BioDex personal con filtros y búsqueda
  • ✓ Notificaciones push de especies cercanas
  • ✓ Integración con wallet BioCoin
🔗

Blockchain Polygon

  • ✓ Smart contracts para distribución de BIO
  • ✓ NFTs de especies legendarias (ERC-721)
  • ✓ Registro inmutable de descubrimientos
  • ✓ Tablas de clasificación descentralizadas
  • ✓ Transacciones de bajo costo (<$0.01)
🤖

IA de Identificación

  • ✓ Modelo entrenado con 1,280 especies colombianas
  • ✓ Reconocimiento por foto, sonido o descripción
  • ✓ Validación comunitaria (crowdsourcing)
  • ✓ Integración con iNaturalist y GBIF
  • ✓ Actualización continua con nuevos avistamientos
📡

IoT Biodiversidad

  • ✓ Cámaras trampa para mamíferos nocturnos
  • ✓ Sensores acústicos para aves e insectos
  • ✓ Estaciones meteorológicas micro-climáticas
  • ✓ Alertas automáticas de especies raras
  • ✓ Datos abiertos para investigación científica
